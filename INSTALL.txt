SETUP

1. Delete the old README/assets/workflow files you no longer want.
2. Upload ALL files from this package preserving the folders.
3. Commit to main.

4. Repository > Settings > Actions > General
   Workflow permissions:
   Select "Read and write permissions".

5. Actions > Update language telemetry > Run workflow.
6. Actions > Generate contribution signal > Run workflow.

After both complete successfully:
- languages.svg displays your live language percentages.
- the cyan contribution snake appears automatically.
- hologram.svg and typing.svg animate directly in the README.
- the typing panel cycles through your profile statements automatically.

The profile-view badge is external and updates automatically.
